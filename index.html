Automated File Organizer

A professional Python automation project developed during my internship at Softnex Company. This tool automatically organizes files, handles duplicates, logs activity, and supports recursive scanning.

Project Completed 🚀

🚀 Features

📁 Auto Organization

Automatically sorts files into folders based on extension.

🔍 Recursive Scan

Scans subfolders and organizes nested files automatically.

🛡 Duplicate Handling

Prevents overwriting using smart renaming.

📝 Logging

Creates organizer.log for tracking activity.

⚙ Dry Run

Preview file movement without actual changes.

💻 CLI Support

Run using command-line arguments.
